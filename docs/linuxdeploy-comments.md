# AppDir / appimagetool 固定注释标准（含 linuxdeploy）

本文件只收录需要跨项目统一复用的注释，适用于脚本、聊天拟稿和修改方案。标准参考为 [Joplin（GTK）](../joplin/build_joplin.sh)、[XnView MP（Qt）](../xnviewmp/build_xnviewmp.sh) 和 [MediaInfo（CLI）](../mediainfo/build_mediainfo_linuxdeploy.sh)，流程见 [linuxdeploy 规范](../linuxdeploy_projects.md)。

- 同一用途逐字复用固定原文，包括 `# `、术语和标点；已确认的注释不改写。
- GTK、Qt 及资源注释按实际需要使用，不为套用注释增加配置。
- 软件专属的修复、路径调整、补库及其注释只记入本项目的 `docs/template-deviations.md`，不加入公共表，也不要求先在这里登记。
- 新增公共用语须经用户确认。注释放在对应命令或命令块正上方，分区、顺序和空行遵循对应参考脚本。

直接 appimagetool 模式复用适用的分区及通用注释，省略 linuxdeploy 初始化、部署、插件和中间输出。既有 linuxdeploy 固定原文保持不变，不为直接模式增加无关步骤。

直接封装的通用参考是 [Kitty](../kitty/build_kitty.sh)。两种模式共用的分区和注释同时对照 Joplin、XnView MP 和 MediaInfo 的适用阶段。参见[四个通用标准参考](../linuxdeploy_projects.md#四个通用标准参考)。

自定义 AppRun 必须内联在 `build_*.sh`，并使用生成完整根 AppRun 的固定注释。仅正文过长且经用户批准、已记录的情况可独立保存，届时按实际复制操作使用注释。见 [AppRun 内联规则](../linuxdeploy_projects.md#apprun-与框架配置)。

直接模式与 linuxdeploy 对同一用途使用同一条固定原文，不因省略部署步骤就改写注释、另起分区名称或放宽排版要求。没有对应操作的标题和注释省略；描述与实际行为不符时，不为逐字套用而改变已确认的命令或专属说明。

阶段顺序在实际依赖允许时尽量对齐，已验证的必要顺序继续保留，并在应用差异说明中写明原因。适用范围和具体边界见 [与 linuxdeploy 标准尽量对齐](../linuxdeploy_projects.md#与-linuxdeploy-标准尽量对齐)。

## 固定分区标题

按实际阶段使用，顺序和原文固定。标题逐字复制，不再自行调整两侧 `#` 的数量。

```text
############# 准备构建目录 #############
############# 准备构建环境 #############
############# 下载打包工具 #############
############ 初始化 AppDir #############
############ 下载并准备应用 #############
########## 准备桌面资源和运行库 #########
############# 准备 AppRun ##############
############### 核心打包 ###############
############### 整理产物 ###############
```

## 按需使用的语言与资源注释

界面中文注释只用于已核实具有中文翻译、且本次明确采用中文界面的程序；生成 locale 还可用于已经说明的中文区域格式需求。命令行工具及不具备中文翻译的 GUI 不因套用模板而增加中文环境；locale 数据不等于界面翻译，也不等于输入法。适用边界见 [linuxdeploy 中文配置](../linuxdeploy_projects.md#中文环境与输入法的适用范围)。

只在当前应用实际采用对应配置或资源时使用，不要求每个程序都增加这些步骤。

| 适用内容 | 固定注释原文 |
| --- | --- |
| 构建时生成包内中文 locale | `# 在包里生成中文 locale，运行时不依赖用户机器是否生成过。` |
| AppRun 设置简体中文界面环境 | `# 设置简体中文界面环境。` |
| 下载并解包所需图标与主题包 | `# 下载并解包应用所需的图标与主题资源。` |
| 收集实际需要的 NSS 核心库和动态加载模块 | `# 复制构建环境中的 NSS 核心库及其配套动态加载模块。` |

NSS 注释按实际运行库需求使用，不因 Joplin 使用 GTK 就认定所有 GTK 程序都需要 NSS；图标和主题包同样按应用实际需要选择。
