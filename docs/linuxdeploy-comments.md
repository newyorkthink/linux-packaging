# linuxdeploy 固定注释标准

本文件只收录需要跨项目统一复用的注释，适用于脚本、聊天拟稿和修改方案。标准参考为 [Joplin（GTK）](../joplin/build_joplin.sh)、[XnView MP（Qt）](../xnviewmp/build_xnviewmp.sh) 和 [MediaInfo（CLI）](../mediainfo/build_mediainfo_linuxdeploy.sh)，流程见 [linuxdeploy 规范](../linuxdeploy_projects.md)。

- 同一用途逐字复用固定原文，包括 `# `、术语和标点；已确认的注释不改写。
- GTK、Qt 及资源注释按实际需要使用，不为套用注释增加配置。
- 软件专属的修复、路径调整、补库及其注释只记入本项目的 `docs/template-deviations.md`，不加入公共表，也不要求先在这里登记。
- 新增公共用语须经用户确认。注释放在对应命令或命令块正上方，分区、顺序和空行遵循对应参考脚本。

## 固定分区标题

按实际阶段使用，顺序和原文固定。

```bash
###### 准备构建目录 ######
###### 准备构建环境 ######
###### 下载打包工具 ######
###### 初始化 AppDir ######
###### 下载并准备应用 ######
###### 准备桌面资源和运行库 ######
###### 准备 AppRun ######
###### 核心打包 ######
###### 整理产物 ######
```

## 通用流程固定注释

以下原文沿用三个参考脚本。APT 同版本解包适用于采用该来源的项目，不限于 CLI。

| 用途 | 固定注释原文 |
| --- | --- |
| 构建脚本及生成的 AppRun 的严格模式 | `# 启用严格模式，在命令执行失败、引用未定义变量或管道执行失败时退出。` |
| 获取构建脚本或 AppRun 所在目录 | `# 获取脚本所在目录的绝对路径。` |
| 准备构建工作目录 | `# 设置构建路径，并清理、重建当前应用的 source、AppDir 和 dist 目录。` |
| 安装构建工具及当前应用的依赖 | `# 安装构建工具和应用所需的依赖包。` |
| 下载打包工具并加载环境配置 | `# 下载并校验打包工具及所需插件，随后加载构建环境配置。` |
| 第一次空 AppDir 初始化 | `# 首次运行 linuxdeploy，创建 AppDir 的基础目录。` |
| 下载、校验、安装并解包同一份官方安装包 | `# 下载并校验官方安装包，将其安装到构建环境并解包到 AppDir，成功后返回版本号。` |
| 下载已安装版本的 APT 软件包并解包 | `# 下载已安装版本的软件包并解包到 AppDir，成功后返回版本号。` |
| 生成完整根 AppRun | `# 在 AppDir 根目录创建完整的 AppRun 启动脚本。` |
| 设置 PATH、LD_LIBRARY_PATH 和 XDG_DATA_DIRS | `# 设置程序、运行库和共享数据的搜索路径。` |
| 执行真实程序并转交命令行参数 | `# 启动包内程序，并保留传入的命令行参数。` |
| 为 AppRun 添加执行权限 | `# 为启动脚本添加执行权限。` |
| 第二次 linuxdeploy 部署与中间输出 | `# 再次运行 linuxdeploy，部署运行资源并生成中间 AppImage。` |

## 按需使用的语言与资源注释

只在当前应用实际采用对应配置或资源时使用，不要求每个程序都增加这些步骤。

| 适用内容 | 固定注释原文 |
| --- | --- |
| AppRun 设置简体中文界面环境 | `# 设置简体中文界面环境。` |
| 下载并解包所需图标与主题包 | `# 下载并解包应用所需的图标与主题资源。` |
| 收集实际需要的 NSS 核心库和动态加载模块 | `# 复制构建环境中的 NSS 核心库及其配套动态加载模块。` |

NSS 注释按实际运行库需求使用，不因 Joplin 使用 GTK 就认定所有 GTK 程序都需要 NSS；图标和主题包同样按应用实际需要选择。
