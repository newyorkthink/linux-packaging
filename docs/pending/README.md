## 任务维护

- 新增任务时，在本目录创建按主题命名的独立文档，并同步更新上表。文档不使用日期或时间戳命名。
- 任务文档只说明尚需完成的工作、已有可靠证据和验收条件；实际修改仍须遵守仓库 `AGENTS.md` 的逐次授权、稳定基线和提交规则。
- 任务完成且完成相应验收后，**必须删除已经无用的待办文档及本索引中的对应条目**，不能让已解决的问题继续显示为待办。保留有复用价值的目录规则；既有故障史、技术依据和已验证修复记录仍按原有文档规则保存，不因清理待办而删除。
