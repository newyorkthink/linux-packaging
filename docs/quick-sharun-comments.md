# quick-sharun 固定注释标准

本文件只收录跨项目需要统一复用的注释，适用于脚本、聊天拟稿和修改方案。流程遵循 [anylinux_projects.md](../anylinux_projects.md)。

按标准重写时，固定注释及位置以 [quick-sharun 唯一标准模板](../anylinux_projects.md#唯一标准模板) 为准。

- 同一用途逐字复用原文，包括 `# `、术语和标点；代码、注释位置、缩进及空行仍以对应标准模板为准。
- 新增、修改或删除公共注释时，必须在同一次修改、同一提交中同步覆盖全部包含对应公共操作的 quick-sharun 标准模板，不能只更新本表或其中一份模板。例如，`# 收集程序及其运行依赖。` 不能只给某一份模板单独添加；注释、对应调用及相邻空行须按 [公共部分必须全部同步修改](../anylinux_projects.md#公共部分必须全部同步修改) 一并维护。
- 按已确认的程序来源、技术栈及实际配置选用，不为套用注释增加变量或步骤；命令行程序不添加 GUI 中文配置，既有批准的例外保持原样。
- 应用专属 hook、辅助程序、库路径、运行参数和兼容处理的注释留在该应用的说明中，不加入公共表。现有标准脚本不因整理本文而批量改写。

## 来源标注与专项用途

- 公共统一注释按对应固定表逐字复用。`# `、正文、术语、空格、标点、所在位置及相邻空行必须与标准一致，不得增字、漏字、换词或另加解释行。
- `# 本仓库兼容处理：` 仅用于本仓库自行实现的兼容逻辑。
- `# 复用官方代码：` 仅用于逐字复用的上游命令或代码块。
- `# 文件内容复用官方代码：` 仅用于内容原样复用的上游独立文件，注释紧贴引用或复制该文件的命令。
- 三种来源标注的前缀必须逐字使用。已有固定正文的，整行逐字复用；无固定正文的，只写对应操作的用途。脚本不得另加 `# 来源：` 行，也不得在固定注释中插入上游名称或链接。上游仓库、完整 commit、原文件路径和固定链接统一记在应用的差异文档中。
- 上述要求适用于草稿、修改方案和提交文件。没有对应操作的固定注释按模板省略，新增或修改公共原文须先取得用户确认。

直接复用已核实的官方依赖收集命令时，逐字使用 `# 复用官方代码：收集程序及其运行依赖。`，不得改用表中的本仓库调用说明。

其余官方代码、官方独立文件与本仓库兼容处理的来源标注及既定用途，继续遵循 [现有来源注释表](../anylinux_projects.md#官方复用与本仓库兼容处理的注释)，不将其中的应用专属处理变成通用步骤。已确认注释没有适用的公共条目时，保留原文，不擅自换词；确需新增公共表述时先说明用途并取得确认。

分区标题、命令排列和空行继续使用对应 quick-sharun 标准，不套用 linuxdeploy 的分区，也不另造一套流程。
