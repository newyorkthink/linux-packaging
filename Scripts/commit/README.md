# 提交维护

| 脚本 | 用途 |
| --- | --- |
| [format_submission.js](./format_submission.md) | 按仓库规则生成提交说明，按文档模板生成实机验证记录。 |
| [rollback_commit.js](./rollback_commit.md) | 预览并经用户明确同意后撤回 `main` 最新的一笔提交。 |
| [git_commit.py](./git_commit.md) | 个人电脑本地仓库工作区按固定格式预览、执行或撤回本地 Git 提交。 |
| [check_changes.js](./check_changes.md) | 在本地和云端只读核对暂存内容或提交的改动范围与 Git 文件模式。 |
| [check_file_modes.sh](./check_file_modes.md) | 个人电脑本地仓库工作区只读核查全仓及未跟踪新文件权限，并按明确清单修正执行位。 |
