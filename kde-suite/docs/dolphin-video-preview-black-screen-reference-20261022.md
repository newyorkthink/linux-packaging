# Dolphin 视频预览全程黑屏问题记录（2026-10-22）

**状态：尚未修复，仅供排查参考；本次只记录，不加入修复代码。**

## 问题与实机结果

Dolphin 右侧信息面板播放部分视频时有声音，但直到播放结束仍然黑屏；另一些视频可以正常显示。

临时禁用硬件解码后，实机仍然全程黑屏。提供的日志显示 H.264 最终使用软件解码，因此禁用硬件解码不是本次问题的有效修复。

## 云端检查与验证边界

六份 H.264 样本均能通过 FFmpeg 完整解码。四份约为 1 fps，两份动态视频约为 25.46 fps。

使用 KDE Suite 成品内的 Qt Multimedia 进行云端检查时，默认设置下，四份低帧率样本延迟数秒后能够出画面，两份动态视频能够正常出画面。限制解码线程数或采用单 CPU 对照，可以改善云端首帧延迟，但未证明能够解决实机全程黑屏。

显式启用 Qt 低延迟播放选项后，四份低帧率样本反而全程没有输出视频帧。该结果来自改变测试程序选项，不能认定与实机故障同源，也不能作为修复方案。

云端使用 offscreen 显示，没有真实显卡和音频输出设备，未完成完整 Dolphin 界面的实机等效复现。目前没有锁定根因，不能确定属于上游问题还是本仓库的打包问题。

## 当前处理决定

保留现有实现，只新增本文档。不加入补丁、预加载、线程或 CPU 限制、低延迟选项及其他启动干预，不修改现有脚本、依赖、README 和工作流。

没有新的有效证据及用户明确授权时，不重复上述失败方向，不把云端首帧延迟改善描述为实机黑屏已经修复。
