# 检查与修正仓库文件权限

## 用途与影响

入口：[check_file_modes.sh](./check_file_modes.sh)。面向个人电脑本地仓库工作区，按 [AGENTS.md](../../AGENTS.md#永久置顶规则仓库文件权限统一规范不可豁免) 核对全仓已跟踪文件与工作区未跟踪文件的权限模式，并在获准后仅对明确列出的文件修正工作区执行位。

- 默认模式只读，不修改文件、索引或提交历史。
- 检查项包括：所有 `.sh` 是否为 `100755`；常见文档、配置、图片、补丁和源码等普通文件是否为 `100644`；以及已跟踪文件的索引模式与工作区执行位是否一致。
- 跳过符号链接（`120000`）与子模块（`160000`）；对无固定扩展名规则的可执行文件（例如 `AppRun`、`wrapper`、直接执行的 Python 脚本和 hook），保留原有 Git 模式，只检查其工作区执行位是否漂移。
- `--fix` 只对明确列出的普通文件执行 `chmod 0755` 或 `chmod 0644`，不改写文件内容，也不自动暂存或提交，方便随后交给 [sync_repo.sh](../sync/sync_repo.md) 或 [git_commit.py](./git_commit.md) 统一提交。

## 运行条件

- Linux 环境、Bash 4.4 或更新版本、Git、`readlink`、`dirname` 与 `chmod`。
- 脚本根据自身位置定位所属 Git 工作区根目录，不受当前终端目录影响。
- 不能设置 `GIT_DIR`、`GIT_WORK_TREE`、`GIT_COMMON_DIR`、`GIT_INDEX_FILE`、`GIT_OBJECT_DIRECTORY`、`GIT_ALTERNATE_OBJECT_DIRECTORIES`、`GIT_NAMESPACE` 等重定向环境变量。
- 本脚本只用于本地核查与获准修正，不接入 GitHub Actions，不自动提交或推送。

## 使用方法

以下命令在 Linux 终端的仓库根目录执行：

```bash
# 查看脚本帮助，不访问仓库
./scripts/commit/check_file_modes.sh --help

# 只读扫描全仓已跟踪文件及未跟踪新文件的权限模式
./scripts/commit/check_file_modes.sh

# 取得本次明确同意后，仅修正指定文件的工作区权限（路径需按实际文件替换）
./scripts/commit/check_file_modes.sh --fix -- "<文件路径1>" "<文件路径2>"
```

## 参数说明

| 参数 | 行为 |
| --- | --- |
| 无参数 | 只读扫描全仓已跟踪文件与未被 `.gitignore` 忽略的新文件，输出异常文件路径、当前模式、目标模式和原因 |
| `--fix -- <文件...>` | 逐个校验相对仓库根目录的普通文件路径，并按规范只修改这些文件的工作区权限（`0755` 或 `0644`）；拒绝目录、符号链接、重复路径、绝对路径以及含 `.` / `..` / `.git` 的路径 |
| `--help`、`-h`、`/help` | 输出用法说明后退出，不访问仓库 |

## 执行结果

| 状态 | 结果 |
| --- | --- |
| 全仓及未跟踪新文件无异常 | 输出已扫描数量并提示通过，返回 `0` |
| 存在已修正工作区权限但尚未暂存的已跟踪文件 | 提示“待提交模式变更”，不阻断后续 `sync_repo.sh push`，返回 `0` |
| 存在不符合规范或执行位漂移的文件 | 逐行列出异常路径、当前模式、目标模式与原因，返回 `1` |
| `--fix` 完成 | 输出每个文件的更新情况（未自动暂存或提交），返回 `0` |
| 参数格式错误或路径非法 | 输出参数错误说明并停止，返回 `2` |
