# 仓库维护脚本

这里存放在终端中明确调用、可通过参数复用的仓库维护工具。本页只维护分类入口和统一约定。

| --- | --- |

## 统一组织方式

| 层级 | 位置 | 内容 |
| --- | --- | --- |
| 总索引 | `scripts/README.md` | 分类入口、目录分工和通用约定 |
| 分类索引 | `scripts/<分类>/README.md` | 该类脚本清单、用途和详细说明链接 |
| 单个脚本说明 | `scripts/<分类>/<脚本名>.md` | 与脚本同目录、同名，只更换扩展名 |

新增脚本按实际用途归入已有分类；确需新分类时再创建目录，并登记到本页。分类名和脚本名使用稳定的功能名称，不带日期或版本号，不预建空分类。

每个脚本的说明统一按“用途与影响、运行条件、使用方法、参数说明、执行结果”组织，保留必要的实现依据。具体命令、参数表和异常处理只写在对应说明中，不逐项展开到总索引或分类索引。

新增、移动或重命名脚本时，同步维护同名说明、分类索引、总索引及相关外部引用。外部通用导航链接到本页，具体任务文档直接链接到对应脚本说明。

## 目录分工

| 目录 | 用途 |
| --- | --- |
| `scripts/` | 人工或 AI 经授权后调用的仓库维护工具 |
| `common/` | 应用构建复用的下载、校验、安装、解包和打包入口 |
| `.github/scripts/` | GitHub Actions 调度、构建和发布使用的脚本 |

维护脚本不自动接入构建或定时任务。应用构建继续调用 `common/`；Actions 的既有入口继续放在 `.github/scripts/`。项目归档与恢复的完整步骤见 [归档说明](../archive/README.md)，其他维护入口见 [维护者指南](../docs/maintainer-guide.md)。

## 公开内容约定

代码、注释和示例使用通用参数或占位符，不写入个人路径、主机名、设备、网络配置、账号配置、令牌或凭据。运行时传入的参数、认证输出、截图和本机日志不能直接作为公共示例提交；只记录完成维护所需的公开结果与验证范围。
